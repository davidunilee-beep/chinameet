# Chinameet · 중국어 기초 학습

`중국어학습앱.html`의 학습 화면과 데이터를 기반으로 배포합니다. 단어·병음·한국어 뜻·예문·성조 표시, 카테고리 탐색, 발음 듣기, 따라 말하기를 제공합니다. 최초의 영상 플레이어 배포본은 학습 앱으로 교체했습니다.

운영 주소: https://chinameet.vercel.app/

## 설치

- PC Chrome·Edge: 상단 **PC 앱 다운로드** 또는 브라우저 설치 메뉴를 사용합니다.
- Windows: **PC 바로가기 저장**으로 `Chinameet.url`을 다운로드할 수 있습니다. 운영 주소를 기본 브라우저에서 여는 인터넷 바로가기입니다.
- Android Chrome: **앱 설치하기**로 브라우저 설치 창을 엽니다. 설치 가능 여부는 브라우저가 결정합니다.
- iPhone·iPad: Safari의 공유 → 홈 화면에 추가를 선택합니다.

앱 화면과 학습 데이터는 첫 온라인 접속 후 캐시됩니다. 발음은 기기의 중국어 음성 지원에 따라 다르며, 따라 말하기는 지원 브라우저·마이크 권한·인터넷이 필요할 수 있습니다. 학습 현황은 원본과 동일하게 실행 중 메모리에만 저장되며 새로고침하면 초기화됩니다. 로그인과 기기 간 동기화는 포함하지 않습니다.

## 개발·배포

- 원본은 `중국어학습앱.html`이며 변경하지 않았습니다.
- `node scripts/prepare-app.cjs`가 원본에 설치 UI를 추가해 `index.html`을 생성합니다. 단어 데이터와 원본 스타일을 유지하고, 음성 인식 중지 시 변수 범위 오류와 설치 안내 내 키보드 간섭을 수정합니다.
- `node scripts/serve.cjs` → http://127.0.0.1:4175
- `node --test tests/*.test.cjs`
- Vercel: Other / 저장소 루트 / 빌드 명령 없음 / Output Directory `.`. GitHub main 커밋에서 자동 배포됩니다.
